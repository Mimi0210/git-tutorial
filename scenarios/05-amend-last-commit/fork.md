# Fork — Scenario 05

> Commit thiếu file → thêm vào commit vừa tạo

## Steps

1. Stage file.
2. **Commit → Amend**.
3. Push (force-with-lease nếu cần).

## Equivalent CLI

```bash
git add package.json
git commit --amend --no-edit
```
