# Fork — Scenario 09

> Chỉ merge một số feature từ dev sang main

## Steps

1. Checkout `main`.
2. Chọn commit trên `dev` → **Cherry-pick**.
3. Lặp cho từng feature được duyệt → Push.

## Equivalent CLI

```bash
git cherry-pick <commit-A>
git cherry-pick <commit-C>
```
