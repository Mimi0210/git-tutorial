# GitHub Desktop — Scenario 07

> Muốn quay lại commit cũ

## Steps

1. **History** → chọn commit.
2. **Revert this commit** (an toàn).
3. Reset chỉ dùng có chủ đích trên branch riêng.

## Equivalent CLI

```bash
git revert <commit>
# hoặc (local):
git reset --hard <commit>
```
